# Customer Retention & Behavior Analysis

## Project Overview

This project analyzes customer purchasing behavior using more than one million transaction records from a UK-based online retailer

The project focuses on customer retention, purchasing behavior, customer value, and repeat business.

## Tools

- Excel - initial data inspection
- Power Query - data cleaning, transformation, and normalization
- PostgreSQL - relational modeling and analysis
- Python / pandas - large-data export and validation
- Power BI - dashboard development
