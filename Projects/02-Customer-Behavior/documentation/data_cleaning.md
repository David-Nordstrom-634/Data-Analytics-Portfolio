## Missing Customer ID
- Retained for overall business analysis.
- Excluded when customer identity is required.

## Missing Description
- Transactions retained.
- Canonical product descriptions created seperately.

## Bad Debt Adjustments
- Excluded from sales/customer analysis.

## Cancellations / Returns
- Retained.
- Treated seperately depending on the metric.

## Exact Duplicate Rows
- Retained because the source does not provide enough evidence to determine whether they are erroneous.

## Product Descriptions
- StockCode treated as the stable product identifier.
- Most frequently occuring valid description selected as the canonical description.
- Products without a reliable description labeled "UNKNOWN DESCRIPTION."

## Customer Analysis Rules

### Identified Customers
Customer-level analysis includes only transactions associated with a valid Customer ID. Transactions without a Customer ID remain available for overall business analysis but are excluded when customer identity is required.

### Purchases
Completed purchases are identified as transactions that are not cancellation invoices and have positive quantities.

### Returns and Cancellations
Invoices beginning with "C" and/or transaction lines with negative quantities are classified as returns/cancellations.

Returns are retained when calculating net customer sales because they reduce the actual value generated by a customer.

### Customer Value

Gross Sales:
Sum of completed purchase transaction value before returns.

Net Sales:
Sum of transaction value including the negative effect of returns/cancellations.

Transaction value is calculated as:

Quantity x Price

### Repeat Customers
A repeat customer is an identified customer with more than one completed purchase during the analysis period.

### Purchase Frequency
Purchase count is measured using distinct completed invoices rather than transaction lines.

Average days between purchases is calculated for repeat customers using the time between consecutive completed purchase invoices.
